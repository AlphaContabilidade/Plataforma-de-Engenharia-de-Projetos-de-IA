# Claude

Leia e siga `AGENTS.md` e `PROTOCOLO-UNIVERSAL-DA-IA.md` antes de agir.

Este repositório não exige uma versão específica do Claude. Use as capacidades disponíveis
para ler, editar, executar e testar, mas preserve o contrato independente de fornecedor.
O núcleo deve continuar funcionando apenas com Python 3.11+:

```bash
python iniciar.py verificar
python iniciar.py interface
```

Não trate recursos exclusivos do Claude como requisito do produto. Quando outro modelo
receber o mesmo clone, ele deve conseguir seguir o mesmo fluxo e os mesmos gates.
